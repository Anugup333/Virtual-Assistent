# 🤖 AI Assistant (Voice + GUI)

A beginner-friendly AI Assistant project built with **Python**, using **Tkinter** for the GUI, **speech recognition**, and **text-to-speech** capabilities. It can respond to text or voice commands, perform simple tasks like telling the time, opening websites, reporting weather, and more.

---

## 🧠 Features

- 🎤 Voice input (speech-to-text using Google API)
- 💬 Text input via GUI
- 🗣️ AI Assistant speaks back responses
- 🕒 Tells the current time
- 🌦️ Provides current weather information (via web scraping)
- 🔗 Opens websites (YouTube, Google, Spotify)
- ❌ Can be shut down with a voice or text command like "shutdown"

## 🛠 Tech Stack

- `Python 3.x`
- `Tkinter` – for GUI
- `speech_recognition` – for converting speech to text
- `pyttsx3` – for converting text to speech
- `Pillow` – for displaying assistant image in GUI
- `requests`, `BeautifulSoup` – for fetching weather info
